# Changelog

All notable changes to this project are documented here.

## [1.1.0] - 2026-08-25

### Added

- Expanded web application playbook covering subdomain and virtual-host enumeration, source analysis, Git service workflows, injection families, XPath, XML and XXE, XSS, SSRF, uploads, API, GraphQL, WebSocket, CORS, CSRF, cache, proxy, and dependency triage.
- Git-backed service methodology for Gitea, GitLab, GitHub Enterprise, Bitbucket Server, exposed `.git` directories, CI/CD files, registries, issues, snippets, releases, and commit history review.

## [1.0.1] - 2026-08-25

### Added

- README badges for validation, release, license, and supported skill targets.
- Explicit unofficial branding guidance.
- Validator checks for shared reference and template drift between Claude and Codex packages.

### Changed

- Removed the external HTB Academy logo hotlink from the README.

## [1.0.0] - 2026-08-25

### Added

- Expanded progressive-disclosure entrypoints for Claude and Codex.
- Original playbooks for machines, challenges, Sherlocks, ProLabs, web applications, privilege boundaries, Windows and Active Directory, forensics, malware analysis, SSH pivoting, exploit review, and tooling.
- User-supplied nimux command-surface reference and version-aware integration guide.
- Complete nimux installation paths for release binary, Debian package, Docker, BlackArch, Arch AUR, and Nimble, with post-install version and help verification.
- Dedicated machine, challenge, Sherlock, ProLab, hypothesis, command-log, engagement-notes, and final-report templates.
- Official source and compliance map that prohibits HTB writeup scraping, active-content spoilers, and protected-content AI dataset construction.

## [0.1.0] - 2026-08-25

### Added

- Claude-oriented Hack The Box skill with interactive checkpoints and evidence-led reasoning.
- Codex-oriented Hack The Box skill with local-first analysis and reproducible execution rules.
- Shared service-enumeration reference.
- Engagement notes and final-report templates.
- Claude and Codex project instruction files.
- MIT license, contribution guidance, security policy, and conservative `.gitignore` rules.
- Dependency-free local validator and GitHub Actions workflow.
