# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-08-25

### Added

- Expanded progressive-disclosure entrypoints for Claude and Codex.
- Original playbooks for machines, challenges, Sherlocks, ProLabs, web applications, privilege boundaries, Windows and Active Directory, forensics, malware analysis, SSH pivoting, exploit review, and tooling.
- User-supplied nimux command-surface reference and version-aware integration guide.
- Complete nimux installation paths for release binary, Debian package, Docker, BlackArch, Arch AUR, and Nimble, with post-install version and help verification.
- Dedicated machine, challenge, Sherlock, ProLab, hypothesis, command-log, engagement-notes, and final-report templates.
- Official source and compliance map that prohibits HTB writeup scraping, active-content spoilers, and protected-content AI dataset construction.

## [0.1.0] - 2026-08-25

### Added

- Claude-oriented Hack The Box skill with interactive checkpoints and evidence-led reasoning.
- Codex-oriented Hack The Box skill with local-first analysis and reproducible execution rules.
- Shared service-enumeration reference.
- Engagement notes and final-report templates.
